# Mabini Batangas Tourism Website

A beautiful, responsive tourism website showcasing the attractions and activities in Mabini, Batangas, Philippines.

## 🌊 About

This website is designed to promote tourism in Mabini, Batangas - a premier destination known for its pristine beaches, world-class diving sites, and scenic hiking trails. The site features a modern, user-friendly interface that works seamlessly across all devices.

## ✨ Features

- **Responsive Design**: Fully responsive layout that adapts to desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean and professional design with smooth animations
- **Hero Section**: Eye-catching hero section with call-to-action buttons
- **Featured Attractions**: Showcase of top attractions including:
  - Beach Paradise
  - Nature Trails
  - Underwater Adventures
- **Photo Gallery**: Interactive carousel showcasing beautiful images of Mabini
- **Activities Section**: Information about various activities like:
  - Swimming
  - Scuba Diving
  - Mountain Hiking
  - Photography
- **Location Map**: Embedded Google Maps for easy navigation
- **Smooth Scrolling**: Smooth navigation between sections
- **Mobile-Friendly Navigation**: Collapsible navigation menu for mobile devices

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Custom styling with animations and responsive design
- **Bootstrap 5.3.0**: Responsive framework and components
- **Font Awesome 6.0.0**: Icons for better visual appeal
- **Google Maps**: Embedded map for location

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, for development)

### Installation

1. **Clone or download** this repository to your local machine

2. **Ensure all image files** are in the same directory as `index.html`:
   - `mabini logo.png`
   - `Mabini.jpg`
   - `Beach.webp`
   - `Hiking.jpg`
   - `Diving.webp`
   - `slide1.jpg`
   - `slide2.jpg`
   - `slide3.jpg`

3. **Open the website**:
   - Option 1: Simply double-click `index.html` to open in your browser
   - Option 2: Use a local web server (recommended for development):
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js (http-server)
     npx http-server
     
     # Using PHP
     php -S localhost:8000
     ```
     Then navigate to `http://localhost:8000` in your browser

## 📱 Responsive Breakpoints

The website is optimized for the following screen sizes:

- **Desktop**: 992px and above
- **Tablet**: 768px - 992px
- **Mobile**: 576px - 768px
- **Small Mobile**: 400px - 576px
- **Very Small**: Below 400px

## 🎨 Customization

### Colors

The website uses a custom color scheme defined in the CSS:
- Primary Dark: `#052220`
- Primary Teal: `#1d5a64`
- Background Light: `#f8f9fa`

To change colors, update the color values in `style.css` and inline styles in `index.html`.

### Content

To update content:
1. Edit the text directly in `index.html`
2. Replace images with your own (maintain the same file names or update the `src` attributes)
3. Modify section content as needed

### Navigation

The navigation menu can be customized in the navbar section:
- Add/remove menu items
- Update links to point to different sections
- Modify the logo image
